# X01-D02协作控制柜

## 产品简介

X01-D02 是纳博特为新一代协作机器人量身打造的智能控制中枢。将尖端动力学算法与工业级硬件完美融合，为 5/6/7 轴协作机器人提供前所未有的控制精度与操作体验。无论您是追求极致效率的工业制造专家，还是寻求智能升级的产线创新者，X01-D02 都将成为您最值得信赖的自动化伙伴。

X01-D02 协作机器人控制柜，采用纳博特自主研发的先进控制算法和动力学技术，集成了基于动力学的拖动示教、碰撞检测和动力学前馈功能，可快速实现平滑、顺畅的拖动示教，并精准记录与回放运动轨迹。

基于 T507 ARM 处理器，该产品在保障低功耗运行的情况下，能够同时满足工业级应用对实时计算和高水平运营可用性的严苛要求。实时计算能力强，轻松实现密集环境中的时间确定性计算，确保系统运行的极高可靠性与稳定性。

## 产品优势

### 动力学技术

X01-D02 搭载纳博特科技的带载动力学技术，无需额外传感器，即可显著提升机器人在带载情况下的拖拽顺滑度，同时增强碰撞检测的灵敏度，实现毫秒级碰撞检测响应。在动力学前馈技术加持下，大负载机器人运行过程中的抖动稳定时间缩短 90%，抖动幅度减小 75%，确保轨迹精度与作业稳定性。

动力学参数辨识过程实现全自动化，用户只需通过安全测试轨迹，机器人即可自动运行预设轨迹完成动力学参数辨识，无需人工干预计算，大幅降低技术门槛。据资深合作客户反馈，多系统产线部署时间 < 10 分钟，相较市场竞品全线投产时间降低 60%。实现更快部署，加速生产效率。

### 智能操作交互

支持多种编程方式：示教编程、离线编程及创新的拖动示教功能，满足不同用户的操作习惯。点到点、直线、圆弧、样条曲线插补、直线横摆、FLYBY 等多种运动轨迹均支持，实现复杂路径的平滑、精准控制。

配备 16 路隔离数字输入/输出、2 路模拟量输入/输出、RS232/485 串口及 PWM 输出，满足各种外部设备连接需求。8 英寸全触屏专用示教器手持操作，操作界面直观高效，人机交互体验感官提升。

### 兼容性强

一柜在手，全线无忧！X01-D02 完美兼容 5/6/7 轴各类协作机器人，可无缝对接主流视觉、力传感器、安全设备。

支持 Ethernet/IP、Profinet、Modbus TCP/RTU、OPC-UA、CAN 等 20+ 种工业协议，开放的 SDK 接口，让集成商和厂家能够快速定制专属功能，真正实现"一次部署，多项兼容"。

## Q&A

**Q：X01-D02 和 X01 有什么区别？**

A：X01-D02 采用 T507 ARM 处理器，主打动力学技术和低功耗设计，净重 5.6kg；X01 采用 Intel J6412 X86 处理器，主频 2.6GHz，支持 1500W/3000W 功耗可选，净重 6.92kg。两者均支持 5/6/7 轴协作机器人，但 X01-D02 更侧重动力学性能和协作场景。

**Q：X01-D02 的动力学技术有什么优势？**

A：X01-D02 搭载纳博特带载动力学技术，无需额外传感器即可实现毫秒级碰撞检测，大负载运行时抖动稳定时间缩短 90%，抖动幅度减小 75%，拖动示教顺滑度显著提升。

**Q：X01-D02 支持哪些通讯协议？**

A：X01-D02 支持 EtherCAT、Ethernet/IP、CAN、OPC-UA、TCP/IP、ModbusTCP、ModbusRTU 等多种工业通讯协议，并支持 20+ 种工业协议扩展。

**Q：X01-D02 的动力学参数辨识需要人工操作吗？**

A：不需要。动力学参数辨识过程全自动化，用户只需通过安全测试轨迹，机器人即可自动运行预设轨迹完成辨识，多系统产线部署时间 < 10 分钟。

**Q：X01-D02 可以选配 WIFI 吗？**

A：可以。X01-D02 支持选配 2.4G WIFI 模块，实现无线网络连接。
