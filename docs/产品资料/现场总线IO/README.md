# 现场总线IO模块

## 产品系列概述

纳博特现场总线IO模块是面向工业自动化现场的高可靠性分布式IO产品，支持 EtherCAT 等主流现场总线协议。该系列模块采用紧凑型结构设计、模块化组合方式，可灵活适配不同点数需求的自动化系统。

产品线覆盖数字量输入、数字量输出、模拟量输入、模拟量输出等多种信号类型，适用于工业机器人控制柜扩展、自动化产线分布式IO、视觉/传感器系统集成等多种应用场景。

## 产品共同特点

- **EtherCAT 高速总线**：支持 EtherCAT 协议，通讯速率可达 100Mbps，满足实时性要求
- **模块化设计**：DIN 导轨安装，支持热插拔，便于维护与扩展
- **丰富信号类型**：支持数字量（DI/DO）、模拟量（AI/AO）、温度采集等多种信号
- **灵活配置**：可依据实际需求选配不同点数和信号类型的模块
- **紧凑结构**：节省控制柜空间，适合分布式安装
