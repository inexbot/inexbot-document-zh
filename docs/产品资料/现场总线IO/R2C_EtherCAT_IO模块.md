# R2C EtherCAT IO模块

## 产品优势

### 体积小

R2C 尺寸仅为 72×140mm，相比 R4C/R4D（122×200mm）和 R5B（116×210.9mm），体积大幅缩小，可轻松安装在空间受限的控制柜或设备内部，节省安装空间。

### 可扩展

R2C 支持通过 EtherCAT 总线进行级联扩展，可根据实际需求增加更多 IO 节点，灵活扩展系统规模。

### 自带导轨卡槽

R2C 内置标准 DIN 导轨安装卡槽，可直接卡接在 DIN 导轨上，安装和拆卸简便快捷，特别适合标准控制柜的快速布局。

### 质量可靠

R2C 采用工业级设计，支持 24V DC 供电，工作温度范围 0~60°C，相对湿度耐受 95%（无冷凝），适应工业现场复杂环境，总线速率 100Mbps，通信周期最短 200us，确保高速稳定的数据传输。

## Q&A

**Q：R2C 和 R4C/R4D/R5B 有什么区别？**

A：R2C 是紧凑型 IO 模块，尺寸最小（72×140mm），仅提供 16 路 DI + 16 路 DO（MOS 管输出），无模拟量接口和编码器接口，适合空间受限且只需数字量输入/输出的场景；R4C/R4D 尺寸较大（122×200mm），额外提供 2 路 AI + 2 路 AO + 编码器接口 + CAN 扩展；R5B 尺寸最大（116×210.9mm），提供 20 路 DO（16 晶体管+4 继电器）+ 模拟量 + 编码器。

**Q：R2C 支持哪些 EtherCAT 功能？**

A：R2C 支持 100Mbps 总线速率和分布式时钟（DC）功能，最小通信周期可达 200us，可与纳博特控制器及支持标准 EtherCAT 协议的主站设备连接。

**Q：R2C 可以通过总线扩展吗？**

A：可以。R2C 通过 EtherCAT 总线与其他 IO 模块或主站设备级联，实现系统规模扩展。

**Q：R2C 如何安装？**

A：R2C 自带标准 DIN 导轨安装卡槽，可直接卡接在 DIN 导轨上，安装和拆卸简便快捷。

**Q：R2C 的 MOS 管输出有什么特点？**

A：R2C 采用 MOS 管作为数字输出元件，响应速度快、寿命长、无机械磨损，适合高频切换的工业应用场景。

**Q：R2C 的工作温度范围是多少？**

A：R2C 工作温度范围为 0~60°C，存储温度范围更宽，适合工业现场部署。
