# XPC-150-C1100 显控一体机

## 产品简介

XPC-150-C1100 是纳博特推出的高性能显控一体机，搭载 Intel Celeron J1900 四核处理器，运行 Linux 操作系统。该设备将显示界面与人机交互功能高度集成，同时具备 EtherCAT 总线通信能力，适用于工业自动化控制、可视化操作及运动控制等应用场景。

## 产品优势

### 工业级设计

XPC-150-C1100 采用工业级硬件配置，处理器主频 2.0GHz，板载存储 64GB，满足工业现场的稳定性与可靠性要求。

### 丰富通信接口

设备配备 1 个 EtherCAT 接口、1 个 LAN2 网络接口、1 个 USB 3.0 接口、1 个 USB 2.0 接口，以及 1 个 RS232 和 1 个 RS485 串口，接口配置丰富，可灵活对接各类工业设备与传感器。

### 灵活显示输出

支持 VGA 显示输出，分辨率可达 1024×768，可连接外部显示器或触控屏，实现可视化操作与监控。

### 宽电压供电

支持 12-24V DC 输入，电压容忍度 ±10%，适应工业现场不同的电源环境。
