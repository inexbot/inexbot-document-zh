# T30 示教器

## 产品简介

T30 机器人专用示教器是纳博特为工业机器人控制系统设计的标准示教设备，采用 8 寸 TFT 全触屏设计，搭载 Linux+QT 操作系统，配合纳博特控制器实现机器人的示教编程、程序编辑、参数配置与状态监控。

## 产品参数

| 规格 | 参数 |
| :--- | :--- |
| 处理器 | TI Sitara AM335x ARM Cortex-A8 32-bit RISC MicroProcessor，up to 1GHz |

| 功能部件 | 急停开关：1 个；选择开关：1 个；电子手轮：1 个；触摸笔：1 支；选配使能开关（三位）：选配 |
| 额定输入电压/最大功率 | 24V DC / 8W |

## 功能部件

### 急停开关

急停开关是保障操作安全的关键部件，在紧急情况下可立即停止机器人所有运动。

### 选择开关

选择开关用于切换机器人操作模式，控制运行/停止等状态。

### 触摸笔

随机附带触摸笔一支，用于在电阻屏上进行精确操作。

### 使能开关（选配）

三位使能开关为选配功能部件，配合示教模式启用，确保示教过程中机器人在操作人员可控状态下运动。

## Q&A

**Q：T30 示教器支持哪些操作系统？**

A：T30 示教器搭载 Linux+QT 操作系统，界面运行稳定，适合工业环境使用。

**Q：T30 的屏幕是触控的吗？**

A：是的，T30 采用 8 寸 TFT 液晶屏，分辨率 800×600，配备加固型 4 线电阻屏，支持触屏操作。

**Q：T30 支持哪些通讯接口？**

A：T30 支持 RS485、CAN 和 Ethernet 三种通讯接口，可与纳博特控制器稳定连接。

**Q：T30 可以控制几台机器人？**

A：T30 配合纳博特控制器使用，可管理最多 4 台工业机器人，支持多机协同作业。

**Q：T30 的使能开关是标配还是选配？**

A：使能开关为选配部件，用户可根据实际需求选择是否配置。

**Q：T30 和 T31 有什么区别？**

A：T30 采用横版 8 寸屏幕设计，T31 采用竖版 5.6 寸屏幕设计；T31 面向焊接应用进行了深度优化，内置焊接工艺监控面板，T30 适用于通用示教场景。
