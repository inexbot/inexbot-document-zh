# 0x4210 - 散热器过热

## 原因

- 风扇损坏
- 环境温度过高
- 过载后通过关闭电源对过载故障复位，并持续多次
- 伺服驱动器的安装方向、与其它伺服驱动器的间隔不合理
- 伺服驱动器故障
- 驱动器或电机损坏

## 解决方法

- 运行时风扇是否运转，更换风扇或驱动器
- 测量环境温度，改善伺服驱动器的冷却条件，降低环境温度
- 查看故障记录，是否有报过载故障，变更故障复位方法，过载后等待30s后再复位。驱动器、电机选用功率过小，提高驱动器、电机容量，加大加减速时间，降低负载
- 确认伺服驱动器的设置状态，根据伺服驱动器的安装标准进行安装
- 断电5分钟后重启是否依然报故障，重启后如果仍报故障请更换伺服驱动器
