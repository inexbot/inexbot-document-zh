# 0x3210 - 过电压

## 原因

- 电源电压超过允许范围（大于AC260V）
- 制动电阻断线，制动电阻不匹配，导致无法吸收再生能量
- 负载惯量超出允许范围
- 驱动器损坏

## 解决方法

- 测量电源电压，必要时安装电压稳压器
- 检查是否已连接外置再生电阻。检查外置再生电阻是否存在断线或损坏，确保接线正确，如果是电阻已烧毁，则建议更换功率更大的外置电阻（电机功率750W或以下，再生电阻规格=50Ω、≥100W。电机功率750W以上，再生电阻规格为=30Ω、≥100W）
- 延长加减速时间，或者根据负载惯量重新选择合适的驱动器和电机
