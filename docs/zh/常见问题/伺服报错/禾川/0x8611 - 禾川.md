# 0x8611 - 位置偏差过大故障

## 原因

- 伺服电机的UVW接线
- 伺服驱动器增益较低
- 位置指令脉冲的频率较高或超速
- 位置指令加速过大
- 位置偏差超出位置偏差过大故障值(P00.19)设置的值过小
- 伺服驱动器/电机故障

## 解决方法

- 重点确切检查是否存在机械堵转、撞击
- 确认电机动力线UVW电缆的接线，确认接线无误
- 确认伺服驱动器增益是否过低，提高增益
- 尝试降低指令频率后再运行，降低位置指令频率、指令加速度或调整电子齿轮比
- 降低指令加速度后再运行，加入位置指令加减速时间参数等平滑功能
- 确认位置偏差故障值(P00.19)是否合适，增大设定(P00.19）值
- 后台查验运行图形，若有输入没反馈请更换伺服驱动器
