# 0x8611 - 位置跟随误差过大

## 原因

- 电机机械负载存在卡死现象导致电机无法运动
- 上位机位置目标值规划加速度过高
- 伺服参数0x6065和伺服参数0x6066设置过小
- 驱动器调节器参数设置不合理导致位置跟踪性能不理想
- 驱动器内部电路异常

## 解决方法

- 检查机械负载传动方式，确保无卡死等现象
- 适当降低上位机位置目标值规划加速度
- 适当增大伺服参数0x6065和伺服参数0x6066设定值
- 优化调节器参数以提高位置跟踪性能
- 更换驱动器
- 使用DriveStarter波形分析
