# 无法升级程序

## U盘插到示教器上之后，在"版本升级"界面点击【检测升级】按钮，弹出"未找到升级文件"提示

- 重新插拔U盘，确定U盘插好
- 确定U盘内有".zip"格式的升级文件
- 确定拷贝到U盘中的升级文件为".zip"格式，且文件名内没有特殊字符
- U盘插到电脑上，在文件管理器内右键点击U盘，点击"属性"，查看属性框内的"文件系统"格式是否为FAT32，若为NTFS或其他格式，请格式化U盘为FAT32格式
- 确定U盘的接口完好，若已松动请更换U盘

## 选择升级文件，点击【确定】按钮后，弹出了正在升级的界面，但是闪了一下便消失，示教器和控制器都没有自动重启

- 确定所选的升级文件的文件名没有特殊字符，如""、（） 、&、%等
- 确定控制器与示教器是否正常连接。示教器左上角有无显示"连接断开"字样，如果当前连接已断开，不可升级
- 把U盘插到电脑上，使用winrar等解压缩软件打开".zip"升级文件，查看其内容，是否为Qt-tp和nrc.out两个文件，若不是请检查是否拷贝错了文件

## 弹出正在升级的界面后，界面中出现了"等待超时"消息，界面消失且没有自动重启

- 确定控制器与示教器是否正常连接。示教器左上角有无显示"连接断开"字样，如果当前连接已断开，不可升级

## 弹出正在升级的界面后，界面中出现了"复制升级文件失败"消息，界面消失且没有自动重启

- 进入"状态-系统状态"界面，查看各个目录的剩余空间，若有目录的存储空间已达到0.0M，则无法升级程序，请联系技术人员
