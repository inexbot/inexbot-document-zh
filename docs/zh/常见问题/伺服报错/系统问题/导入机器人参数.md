# 导入机器人参数

## 导入机器人参数

- 找到一个FAT32格式的U盘，确定U盘格式及制作FAT32U盘的方法请见"显示伺服未连接"问题的"现象2"
- 在U盘的根目录下新建一个文件夹，名为"configFile123（或其它数字）"
- 将.json配置文件放入该文件夹内
- 将U盘插到示教器上
- 在确保示教器与控制器已连接的情况下（示教器上方没显示红色的"连接断开"），进入到"设置-系统设置"，点击"导入机器人参数"
- 选择configFile123（或其它数字）的文件夹，点击确定
- 选择要导入的参数
- 点击确定
