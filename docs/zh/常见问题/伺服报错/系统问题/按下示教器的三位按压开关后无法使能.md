# 按下示教器的三位按压开关后无法使能

## 按下示教器的三位按压开关后提示"伺服未就绪，请按下MOT键"

- 按下示教器上的"MOT"按钮或点击示教器上方状态栏的伺服状态一栏，点击"伺服就绪"按钮，示教器上方的伺服状态显示闪烁的"伺服就绪"，此时在"示教模式"下按下三位按压开关即可使能

## 伺服在"伺服就绪"状态，按下三位按压开关后依然无法使能

- 确定当前是否为"示教模式"，若不是，请旋转钥匙开关或点击上方状态栏的模式一栏，点击"示教模式"按钮，此时即可上电
- 若在"示教模式"，且伺服在"伺服就绪"状态，按下DEADMAN后伺服依然未使能，请查看控制柜内的伺服上的灯是否有闪烁的红色，若有请在示教器"示教模式"下按下"F1"按钮，然后伺服上的灯若没有报错，则按下三位按压开关后即可使能
- 若伺服、模式均正确，按下三位按压开关后依然不能使能，请检查示教器转接板，接线板上的公共端是否与+24V串接
