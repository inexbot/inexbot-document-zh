# 支持的外部轴类型

NexDroid 控制系统支持以下外部轴类型，可与机器人本体联动实现多轴协同运动。

| 外部轴类型 | 说明 |
| :--- | :--- |
| 单轴转台 | 单轴旋转工作台，用于工件变位 |
| 双轴变位机 | 双轴旋转变位机，支持两轴协同 |
| 地轨 | 单轴直线地轨，扩展机器人行走范围 |
| 直线双轴地轨 | 双轴直线地轨 |
| 直线三轴地轨 | 三轴直线地轨 |

> **说明**：以上列表来自 NexDroid 官网。外部轴通过 EtherCAT 总线接入，支持与机器人联动或独立运动。
