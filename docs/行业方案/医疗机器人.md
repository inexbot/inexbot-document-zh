医疗和手术等领域今天越来越多的应用了机器人的控制技术，例如：

- 专业康复应用
- 微创手术
- 术中放射治疗
- 改善的乳腺癌诊断
- 骨外科手术和非接触式骨骼治疗
- 矫形外科
- 血管造影和混合手术系统
- 美容外科

## 质子中心治疗床

随着放射疗法的引入，肿瘤治疗开始依靠精准的机器人辅助控制技术实现患者精准定位。质子治疗仪是当今世界最先进的无创肿瘤治疗方法。

质子中心治疗床（载人系统），负载可达 300 公斤，用于质子治疗中心的患者定位器，其末端精度可达 0.5mm 以下。纳博特针对这一领域开发的精准算法和误差补偿技术，实现了该设备领域的国产化，目前已经被应用于多个质子治疗中心。

## X 光/CT 中心

利用关节机器人，替代 C 型臂 X 光机或 CT 机，可以提供更高的操作精度，直接在手术室就可以实现 3D 成像效果。

## 骨科机器人

骨科机器人可以依靠视觉技术帮助医生进行辅助病灶定位，提供术前手术流程规划，入钉位置，手术可视化引导等多种操作。

基于机器人仿真和力控技术，可以实现机器人自动避障，避免手术意外发生。
