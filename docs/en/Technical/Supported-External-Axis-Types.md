# Supported External Axis Types

The NexDroid control system supports the following external axis types, which can be coordinated with the robot body for multi-axis synchronized motion.

| External Axis Type | Description |
| :--- | :--- |
| Single-axis rotary table | Single-axis rotary worktable, used for workpiece repositioning |
| Dual-axis positioner | Dual-axis rotary positioner, supporting two-axis coordination |
| Floor rail | Single-axis linear floor rail, extending the robot's travel range |
| Dual-axis linear floor rail | Dual-axis linear floor rail |
| Three-axis linear floor rail | Three-axis linear floor rail |

> **Note**: The above list comes from the NexDroid official website. External axes connect via the EtherCAT bus and support coordinated motion with the robot or independent motion.
