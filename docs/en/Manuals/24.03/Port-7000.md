1.  Find the corresponding protocol to send from the Port 7000 protocol, for example: query robot joint coordinates

{"channel":1,"robot":1,"mode":0,"queryType":["realPosACS"]}

2.  **Convert to Hex:** [ASCII String to Hex Online Conversion Tool - Coding.Tools](https://coding.tools/cn/ascii-to-hex)

![](assets/ldbvxrkaxlnrlob0g1zro.png)

## FAQ

## Format Issues

**Question**: After sending data, no reply is received. How to troubleshoot format issues?

**Answer**:
- Check if the fixed frame header is 4E 66
- Verify the byte length is accurate and converted to hex, use tools to check
- Verify the command word for the corresponding function is accurate, refer to the port protocol
- Check if the data content symbols and data are in English when using ASCII, use JSON validation tool to check
- Verify the data CRC is accurate, use tools to check

## Network Debugging Assistant Issues

**Question**: After sending data using the network debugging assistant, no reply is received. How to resolve?

**Answer**:
- Ensure both sending and receiving are in HEX format
- Check if the network connection is normal
- Confirm the controller IP address and port number (7000) are correct
- Check if the network debugging assistant format settings are accurate
