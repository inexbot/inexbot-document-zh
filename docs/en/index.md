## About iNexBot

Founded in 2015, iNexBot is a technology pioneer in China's high-end motion control field. With "software-defined control, algorithm-driven intelligence" as our core philosophy, we provide a full-stack technology system spanning from underlying hardware, middleware platforms, to upper-layer applications.

Our core technologies include:

- **Multi-axis high-precision motion control** (PC-Based architecture)
- **Robot core algorithms** (kinematics/dynamics modeling, online trajectory planning)
- **Intelligent perception and coordination** (2D/3D vision fusion, force control, multi-agent coordination)
- **Industry process packages** (welding, cutting, dispensing, polishing, spraying, etc.)

Our products are widely used in industrial robots, semiconductors, healthcare, logistics, and new energy vehicles, serving globally renowned customers such as BYD, Foxconn, and Luxshare Precision.

## Knowledge Base Directory Structure

This repository is organized by technical domain and application scenario, enabling developers and engineers to quickly locate information:

### Recommended Document Hierarchy

To improve document accessibility and consistency, the following hierarchy is recommended:

1. **Level 1 Directory**: Classification by document type
   - Product Information: Hardware products, calibration systems, and other product-related documents
   - Technical Information: Technical documents, frequently asked questions and solutions
   - Operation Manuals: Version-specific operation manuals

2. **Level 2 Directory**: Classification by product or technology category
   - Product Information/Control Systems: Controller-related documents
   - Product Information/Calibration: Calibration system-related documents
   - Technical Information/FAQ: Frequently asked questions and solutions

3. **Level 3 Directory**: Classification by version or specific product
   - Operation Manuals/22.07: Operation manual for the July 2022 version

4. **File Naming**: Follow document naming conventions to ensure clear file names

### Navigation Recommendations

- **Browse by Type**: Users can select and view product information, technical information, or operation manuals as needed
- **Browse by Product**: Users can directly view documents related to a specific product
- **Browse by Version**: Users can view operation manuals for a specific version
- **Complete Index**: [Knowledge Base Complete Index](Index.md) - Contains a detailed list of all documents

## Q&A

**Q: What types of documents does this knowledge base contain?**

A: This knowledge base covers four major categories: Product Information (hardware product introductions, selection manuals), Technical Information (supported device models, communication protocols), Operation Manuals (22.07 version, 24.03 version), and Industry Solutions.

**Q: How are operation manuals organized by version?**

A: Operation manuals are classified and stored by version. The 22.07 version contains operation manuals released in July 2022, and the 24.03 version contains operation manuals released in March 2024. There are differences between the two versions in instruction sets and features. Please select the corresponding manual based on the actual controller version.
