## Dispensing Process Overview

Dispensing refers to applying glue or curing agent onto products that need to be sealed, to fix and seal the products.

Traditional dispensing is generally performed by operators using manual glue guns or dispensing needles, controlling the glue flow rate and position. The disadvantage of this method is that it is only suitable for simple dispensing tasks and small-scale production, and cannot guarantee the dispensing success rate or improve dispensing speed.

Automated dispensing refers to using automated equipment, such as robots, for dispensing. Through programming and precise control, high-precision and high-efficiency dispensing can be achieved. Automated dispensing is commonly used for large-scale production and complex dispensing requirements.


## Dispensing Application Classification and Function Overview


In dispensing applications, according to form, they can be divided into: five-axis linkage precision dispensing, high-speed dispensing machines, inline/benchtop dispensing machines, and robot arm dispensing.


Dispensing equipment can be subdivided by function type into actuating mechanisms, driving mechanisms, and control mechanisms:


- The actuating mechanism is mainly responsible for executing the dispensing operation.


- The driving mechanism is mainly responsible for helping the actuating mechanism complete the dispensing operation more accurately and with higher quality.


- The control system is mainly responsible for controlling the entire system.
