## System Solution Introduction

### Solution Overview

A 3D machine vision system detects the position and posture of disorderly stacked packages, sends position signals to the manipulator, and guides it to pick up the packages, efficiently replacing repetitive manual operations and reducing package damage.

![Complex package supply environment](https://inexbot.com/api/cms-assets/uploads/220530/bc91327c1a1f9b8fdadc17f57616d7e4.png)

- Positioning: provides the optimal picking strategy and locates the picking position
- Classification: distinguishes soft bags and cartons to prevent package flinging
- Exception handling: handling of oversized, overweight, deformed, or stuck packages

![Precise positioning of messy packages](https://inexbot.com/api/cms-assets/uploads/220530/e55744e5579c1a308fba09a5b4b85481.png "e55744e5579c1a308fba09a5b4b85481.png")
![Precise positioning of messy packages](https://inexbot.com/api/cms-assets/uploads/220530/b8a9869b06581bd8525db165e9357dab.png)

### Vision System Components

- 1 FM851-E2 industrial 3D camera
- External LED light source
- Software SDK (industrial PC)
- Package Picking software package

## Complete Solution Configuration

Camera:

- Camera hardware: PERCIPIO FM851-E2
- Vision software: Package Picking
- Robot control system: INEXBOT control system

Industrial PC:

- System: Windows 10 Enterprise 64-bit
- Processor: Intel(R) Core(TM) i7-10700F CPU @ 2.90Ghz
- Memory: 16G
- GPU: NVIDIA GeForce GTX 1660 SUPER

Others:

- Light source, suction cups, checkerboard, air pump, etc.

## Overall System Performance

Test condition: 1680 pieces/hour

Cycle time: 2.08 s/piece

Actual operation: > 1500 pieces/hour

Advantage: image acquisition and calculation run in parallel with manipulator motion; the manipulator has zero waiting time throughout the entire process!
