# X02 Integrated Drive-Control Cabinet

## Product Introduction

The X02 integrated drive-control cabinet is a compact control cabinet launched by INEXBOT for collaborative robot applications. Small in size yet mighty in capability, it is suitable for a variety of industrial automation scenarios.

## Product Specifications

| Item | Parameter |
| :--- | :--- |
| Power Input | 220V 10A |
| Ethernet Ports | 1×EtherCAT, 2×Ethernet |
| USB | 1×USB 2.0 |
| COM | 1×RS232, 1×RS485, isolated |
| I/O | 16×isolated DI, 16×isolated DO, 2AI (-10V~10V), 2AO (0V~10V) |
| CAN | 1×CAN |
| Dimensions | 357.5mm × 370mm × 130mm |
| Encoder | 2 channels incremental encoder ABZ (rate 4Mbps, differential input), non-isolated |
| Teach Pendant | (Optional) T30-X collaborative robot dedicated teach pendant: 8-inch TFT full touchscreen, Linux+QT |
| Communication Protocols | EtherCAT, Profinet, Ethernet/IP, CAN, FinsTCP, TCP/IP, ModbusTCP, ModbusRTU |
| Operating Modes | Teach mode, playback mode, remote mode |
| Programming Methods | Teach programming, offline programming, drag teaching |
| Coordinate Systems | Joint coordinate system, robot coordinate system, tool coordinate system, user coordinate system |
| Applications | Arc welding, TIG welding, laser welding, resistance welding (spot welding), stamping, loading/unloading, laser cutting, spraying, dispensing, palletizing, conveyor tracking, etc. |
| Protection Rating | IP20 |
| Overall Weight | 4-axis: 8kg; 6-axis: 9kg |

## Q&A

**Q: How many axes of robots does the X02 support?**

A: The X02 integrated drive-control cabinet supports 4-axis and 6-axis collaborative robots, with overall weights of 8kg and 9kg respectively.

**Q: What are the communication interfaces of the X02?**

A: The X02 is equipped with 1×EtherCAT, 2×Ethernet, 1×RS232, 1×RS485 (isolated), 1×CAN, plus 16×isolated DI, 16×isolated DO, 2×AI, and 2×AO.

**Q: Which encoders does the X02 support?**

A: The X02 supports incremental encoders from Tamagawa and Anchi, with resolutions of 17-bit or 23-bit.

**Q: What is the protection rating of the X02?**

A: The X02 has an IP20 protection rating, suitable for general indoor industrial environments.

**Q: Can a teach pendant be configured with the X02?**

A: Yes. The X02 supports the optional T30-X collaborative robot dedicated teach pendant, featuring an 8-inch TFT full touchscreen running a Linux+QT system.
