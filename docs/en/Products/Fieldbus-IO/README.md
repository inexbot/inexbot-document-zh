# Fieldbus IO Modules

## Product Series Overview

INEXBOT fieldbus IO modules are high-reliability distributed IO products for industrial automation sites, supporting mainstream fieldbus protocols such as EtherCAT. This series adopts a compact structural design with modular combination, flexibly adapting to automation systems with different point-count requirements.

The product line covers digital input, digital output, analog input, analog output, and other signal types, suitable for industrial robot control cabinet expansion, distributed IO on automated production lines, vision/sensor system integration, and other application scenarios.

## Common Product Features

- **EtherCAT high-speed bus**: Supports the EtherCAT protocol with communication rates up to 100Mbps, meeting real-time requirements
- **Modular design**: DIN rail mounting, hot-swappable, easy to maintain and expand
- **Rich signal types**: Supports digital (DI/DO), analog (AI/AO), temperature acquisition, and other signals
- **Flexible configuration**: Modules with different point counts and signal types can be selected based on actual needs
- **Compact structure**: Saves control cabinet space, suitable for distributed installation
