# T31 Vertical Teach Pendant

## Product Introduction

The T31 vertical teach pendant is a dedicated teaching device designed by INEXBOT for industrial robot welding applications. It features a vertical screen layout with a 5.6-inch TFT display (resolution 640×480) and 61 customizable membrane keys, plus a three-position selector switch and an optional enable switch, delivering a professional human-machine interface for welding operations.

## Functional Components

### Emergency Stop Switch

The normally-closed E-stop design complies with industrial safety standards and supports single-contact or dual-contact configurations, allowing rapid shutdown of robot motion in an emergency.

### Mode Selector Switch

A three-position selector switch used to switch robot operating modes, controlling states such as run/teach/remote.

### Enable Switch (Optional)

The three-stage dual-contact enable switch is an optional component that ensures the robot only moves while the operator maintains control during teaching, providing an additional layer of safety.

## Q&A

**Q: What is the difference between the T31 and the T30?**

A: The T31 features a portrait 5.6-inch screen (resolution 640×480), while the T30 features a landscape 8-inch screen (resolution 800×600). The T31 is optimized for welding applications, equipped with 61 customizable keys and 12 customizable LED indicators and supporting richer welding process monitoring functions; the T30 is more general-purpose, with 12 function keys and 12 axis keys.

**Q: What is the protection rating of the T31?**

A: The T31 has an IP 54 protection rating, preventing ingress of splashing water and dust, making it suitable for typical industrial welding environments.

**Q: Can the T31 control multiple robots simultaneously?**

A: Working with an INEXBOT controller, the T31 can manage up to 4 industrial robots, making it ideal for multi-robot coordinated welding stations.

**Q: Which emergency stop switch configurations does the T31 support?**

A: The T31 emergency stop switch is the normally-closed type and supports either single-contact or dual-contact configurations to meet different safety level requirements.

**Q: Is the T31 enable switch standard or optional?**

A: The enable switch is an optional component; users can decide whether to configure it based on their actual needs.

**Q: Does the T31 support offline programming?**

A: Yes. The T31 supports multiple programming methods including teach programming, offline programming, and drag teaching. Combined with the INEXBOT control system, it enables flexible programming operations.

**Q: Can the T31 keys be customized?**

A: Yes. The T31 is equipped with 61 customizable membrane keys and 12 customizable LED indicators. Users can customize key functions according to their actual process requirements.
