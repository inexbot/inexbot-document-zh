# Wireless Remote Control Handheld Box NWH01

## Efficient, Precise — Reach It All with One "Grip"

The INEXBOT NWH01 wireless remote control handheld box is a handheld control device designed for long-distance robot operation and commissioning scenarios. It communicates with the robot controller wirelessly, effectively freeing operators from the constraints of traditional teach box cables. Operators can teach, edit programs, and control the robot's operation over a much larger range, significantly improving operational flexibility and work efficiency.

## Product Introduction

The NWH01 handheld box features a compact design and comfortable grip, supports plug-and-play, and can seamlessly connect with INEXBOT controllers, making it suitable for a variety of industrial robot application scenarios.
