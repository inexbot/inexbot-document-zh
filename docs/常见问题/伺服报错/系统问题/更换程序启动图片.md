# 更换程序启动图片

## 更换程序启动图片

（StartImage.png为走完进度条后的一张图，SoftUpdatingBackground.png为升级程序时的背景图）

- 准备两张图片，分辨率均为800*600，png格式，分别命名为StartImage.png、SoftUpdatingBackground.png（注意大小写），其中后者为升级程序时的背景图片
- 将两个文件压缩为一个.zip压缩包，如background.zip
- 将.zip压缩包放在U盘根目录下，插在示教器上，升级该文件
