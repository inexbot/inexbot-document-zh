# 示教器左上角显示红色的连接断开

## 开机后示教器左上角一直显示红色的“连接断开”，没有变化。

检查控制器与示教器的接线，是否接对，示教器转接盒的网线需要接到控制器标有“示教器”的网口，控制器的另外一个网口需要接到伺服的“IN”网口； - 将一个显示器插在控制器的VGA端口上，查看控制器是否正常开机，若没有正常开机，请重启控制器，若还不能正常开机，请到www.inexbot.com/下载调试软件，通过调试软件更换控制器程序；
切换示教器的权限为管理员，进入“设置-系统设置-IP设置”界面，检查“连接IP”一项是否和控制器的IP相同； - 检查IP设置界面内的示教器IP是否和控制器IP在同一个网段内，即控制器和示教器的IP都为192.168.1.xxx或都为192.168.0.xxx。

## 开机后示教器的左上角经常出现红色的“断开连接”，但是等一会儿会自动连接。

重新插拔示教器，确保航插没有接触不良； - 更换示教器与控制器连接的网线，请使用超六类屏蔽网线。
