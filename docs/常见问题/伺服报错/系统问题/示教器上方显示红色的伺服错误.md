# 示教器上方显示红色的伺服错误

## 示教器上方状态栏伺服状态处显示红色的“伺服错误”。

切换到示教模式； - 检查示教器与控制柜上的急停按钮是否按下，若按下则拔起来后按下示教器上的“F1”按钮清除错误，若没有则继续； - 点击进入“状态-伺服状态”界面； - 记录下伺服报错信息，即各轴报错代码； - 插一个FAT32格式的U盘到示教器上（FAT32格式U盘的检查及制作方法请见“伺服未连接”一节）； - 进入“设置-系统设置”界面，点击“导出控制器日志”，选择“5个”，点击“确定”； - 将U盘内刚导出的“controllerLog(日期-时间)”打包，； - 将打包的文件夹与伺服报错代码提交给厂商，由厂商检测伺服报错原因； - 按下示教器的“F1”按钮，若示教器上方的“伺服错误”消失，则伺服报错清除，可以继续使用； - 若按下“F1”后依然报错，请将伺服、控制器、示教器断电重启。
