# 0xFF0D -清能德创

## EtherCAT过程数据错误

a. 可能原因
i. 上位机位置目标值规划不合理，比如位置目标值有突变
ii. 伺服参数0x60C5和0x6065设置过小
iii. EtherCAT通讯受到干扰
iv.上位控制器与驱动器通讯建立后，位置目标值未做更新（此现象一般发生在首次上使能时）
v. 外部网线通讯有干扰，比如:SM2数据有丢失。
vi.上位控制器有干扰。
b. 处理措施
i. 合理规划上位机位置目标值
ii. 适当增大伺服参数0x60C5和0x6065设置过小
iii. 优化EtherCAT通讯布线，加强抗干扰措施，比如使用超5类屏蔽网线，控制器保证可靠接地等。
iv. 修改上位控制器程序，EtherCAT总线通讯建立，同时更新位置目标值
v.系统可靠接地；系统供电与外部强干扰源供电分开，比如，焊机。
vi.开启平滑预测控制。
c. DriveStarter波形分析
