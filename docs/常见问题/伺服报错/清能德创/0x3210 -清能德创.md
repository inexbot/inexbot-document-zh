# 0x3210 - 直流母线过压

## 原因

- 驱动器动力输入电源电压过大
- 电机快速停止时的能耗制动能量过大
- 电机停止减速度过大
- 能耗制动电阻接线错误
- 能耗制动电阻阻值过大
- 驱动器内部电压采样电路异常
- 驱动器内部能耗制动电路异常

## 解决方法

- 调整驱动器动力输入电源至允许范围
- 减小电机停止减速度
- 检查能耗制动电阻接线并确保接线正确
- 适当减小能耗制动电阻阻值（阻值不能低于允许的最小值），增大能耗制动电阻功率
- 更换驱动器
- 使用DriveStarter波形分析
