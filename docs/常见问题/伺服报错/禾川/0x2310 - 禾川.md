# 0x2310 - 过流故障A

## 原因

- 指令输入与接通伺服同步或指令输入过快
- 外接制动电阻过小或短路
- 电机电缆接触不良
- 电机电缆接地
- 电机UVW电缆短路
- 电机烧坏
- 软件检测出功率晶体管过电流

## 解决方法

- 检查指令输入时序，伺服接通"rdy"后输入指令
- 测量制动电阻阻值是否满足规格，按说明书要求重新选择合理制动电阻
- 检查线缆连接器是否松脱，确保连接器紧固
- 检查电机UVW线与电机接地线之间的绝缘电阻绝缘不良时更换电机
- 检查电机电缆连接UVW是否短路，正确连接电机电缆
- 检查电机各线缆间电阻阻值是否相同，不同则更换电机
- 减小负载。提升驱动器、电机容量，延长加减速时间
- 确认版本号参数P21.36、P21.37、P21.38、为1107/1108/1207或以上，若不符请升级固件
