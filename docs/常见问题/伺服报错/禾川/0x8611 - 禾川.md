# 0x8611 - 禾川

## 位置偏差过大故障

原因
1、伺服电机的UVW接线；
2、伺服驱动器增益较低；
3、位置指令脉冲的频率较高或超速；
4、位置指令加速过大；
5、位置偏差超出位置偏差过大故障值(P00.19)设置的值过小；
6、伺服驱动器/电机故障；
处理措施
1、重点确切检查是否存在机械堵转、撞击；
2、确认电机动力线UVW电缆的接线，确认接线无误；
3、确认伺服驱动器增益是否过低，提高增益；
4、尝试降低指令频率后再运行 降低位置指令频率、指令加速度或调整电子齿轮比；
5、降低指令加速度后再运行 加入位置指令加减速时间参数等平滑功能；
6、确认位置偏差故障值(P00.19)是否合适，增大设定(P00.19）值；
7、后台查验运行图形，若有输入没反馈请更换伺服驱动器；
