# 速度参数

说明："全局速度"表示的是示教器界面上状态栏速度。

![](./assets/xmzzspl1paxled6menuzv.png)

| :--- | :--- | :--- | :--- |
| 关节点动速度 | 关节轴最大点动速度\*全局速度 |
| 直角点动速度 | 直角轴最大点动速度\*全局速度 |
| 单步关节速度 | 全局速度\*指令速度\*关节额定正速<br>最大速度限制：关节额定速度\*30% |
| 单步直角速度 | 全局速度\*指令速度<br>最大速度限制：300mm/s |
| 动态加减速 | 仅支持点到点与直线，当速度到达额定速度后无法再增大 |
| 动态加减速实际应用 | 在一条不支持动态加减速的指令运行期间修改速度，修改后的速度会被应用到下一条运动指令上 |
| 试运行速度 | 同单步指令速度 |
| 倒序速度 | 同单步指令速度 |
| 运行模式 | 点到点：最大轴速度=额定正速度\*指令速度\*全局速度<br>直线：最大线速度=指令速度\*全局速度<br>曲线：以第一条曲线速度为轨迹速度 |

## AI 检索专用问答对 (Q&A for Retrieval)  

**Q: 什么是全局速度？**

A: 全局速度表示的是示教器界面上状态栏显示的速度。

**Q: 关节点动速度如何计算？**

A: 关节点动速度=关节轴最大点动速度\*全局速度。

**Q: 直角点动速度如何计算？**

A: 直角点动速度=直角轴最大点动速度\*全局速度。

**Q: 单步关节速度如何计算？**

A: 单步关节速度=全局速度\*指令速度\*关节额定正速，最大速度限制为关节额定速度的30%。

**Q: 单步直角速度如何计算？**

A: 单步直角速度=全局速度\*指令速度，最大速度限制为300mm/s。

**Q: 动态加减速支持哪些运动模式？**

A: 动态加减速仅支持点到点与直线运动模式，当速度到达额定速度后无法再增大。

**Q: 动态加减速如何实际应用？**

A: 在一条不支持动态加减速的指令运行期间修改速度，修改后的速度会被应用到下一条运动指令上。

**Q: 试运行速度与什么速度相同？**

A: 试运行速度同单步指令速度。

**Q: 倒序速度与什么速度相同？**

A: 倒序速度同单步指令速度。

**Q: 点到点模式的最大轴速度如何计算？**

A: 点到点模式下，最大轴速度=额定正速度\*指令速度\*全局速度。

**Q: 直线模式的最大线速度如何计算？**

A: 直线模式下，最大线速度=指令速度\*全局速度。

**Q: 曲线模式的轨迹速度如何确定？**

A: 曲线模式以第一条曲线速度为轨迹速度。
