# 示教器编程指导手册

## 开机安全确认

1. 检查伺服、控制器、示教盒各部件连接线是否已连接完好。
2. 把机柜面板上的主电源开关旋转到接通（ON）的位置，主电源接通。
3. 按下机柜面板上的绿色伺服启动按钮。
4. 示教器开机成功后确认机器人参数是否正常，参数没有问题后就可以点动机器人。

|   |
| :---- |
| 警告：<br>![](./assets/m1c_qpenjyduf3ei8mltm.png)<br>防止机器人在运动过程中出现飞车现象，示教前请确认急停按钮正常！ |

## 急停按钮的使用确认

1. 在机器人使用前，请分别对控制柜、示教盒上的急停按键进行确认，按下时，伺服电源是否断开。
2. 按控制柜及示教盒上的急停按键。
3. 确认伺服电源关闭，示教器显示伺服报错，控制柜伺服报错灯亮。
4. 清除伺服错误，控制柜伺服报错灯灭，示教器上显示"伺服停止"。
5.  轻按示教器的【DEADMAN】按键（示教器背后的按键），机器人上电，示教器上显示"伺服运行"，表示伺服电源成功接通。

## 机器人配置参数

1. 示教器开机成功后，在【设置】-【从站配置】-【从站列表】界面确认连接的从站个数、从站型号、机器人类型。

![](./assets/yxhu_qa3sxpme41pl-xzx.png)

2. 在【设置】-【机器人参数】-【DH参数】界面确认杆长、耦合比等参数是否正确。

![](./assets/xp_ftlqfiy8n-g1rvsijg.png)

3. 在【设置】-【机器人参数】-【关节参数】界面确认每个关节轴的关节参数。

![](./assets/aul_jlhherzysetrukkp8.png)

4. 示教器开机成功后如果机器人配置参数没有的话，就需要重新导入配置。

导入配置流程：

1. 点击【设置】-【机器人参数】-【机器人类型】界面，设置机器人类型
2. 点击【设置】-【系统配置】-【导入控制器配置】选择配置文件，系统重启后机器人参数配置导入成功

|   |
| :---- |
| 警告：<br>![](./assets/uenda7oxdwp7ls9gzpls3.png)<br>导入的配置文件必须是当前选中机器人的配置文件，配置文件不对会导致在点动机器人时出现飞车现象 |

配置文件导入成功后的注意事项：

1. 伺服顺序：

根据伺服连接顺序，点动机器人，查看伺服从站1是否控制的一轴，伺服从站2是否控制的二轴，以此类推，若不是自行修改。

注意：某些伺服从站存在多合一，从站配置里面机器人轴未必是1234567按照顺序。

2. 模型方向：

当点动机器人的实际方向与机器人模型方向一致时，模型方向数值不变。

当点动机器人的实际方向与机器人模型方向相反，需要在关节参数界面将模型方向数值取反。

3. 零点位置：

点击示教器上面的【零点】，机器人运行到零点位置，机器人回到零点位置后看一下机器人每个轴的位置是否都在零点，如果零点位置有偏差需要重新校准零点。

|   |
| :---- |
| **注释：**<br>![](./assets/s5igjebiyasjqq-4ugmkz.png)<br>- 若出现实际点动机器人关节轴90度，但示教盒上显示的并不是90度，则需要调整减速比或与厂家确认。<br>- 若出现在直角坐标系下，点动坐标轴，机器人走不直的情况，则需要调整DH参数或联系厂家确认。 |

## 点动机器人操作

1. 示教器与控制器连接正常。

2. 伺服、机器人参数正常。

3. 在示教模式下，按下示教器上的【伺服】按键，将伺服停止状态切换至伺服就绪。

4. 轻按示教器的【DEADMAN】按键（示教器背后的按键），不松手，此时听到机器人上电的声音，且"伺服状态"一栏显示为绿色的"伺服运行"。

5. 通过操作示教器右侧物理按键来控制机器人运动。

## 工程界面操作说明

1. 用户权限切换至管理员或者新建用户自定义权限。用户如何自定义权限可以在《示教器功能按键》手册查看。

2. 点击左侧的【工程】，进入工程预览界面。

![](./assets/ir_d2qydxbnrxori1cqoe.png)

### 新建

#### 新建文件夹

1. 点击【工程】进入工程界面。

2. 点击新建，进入新建界面。

3. 下拉框选择文件夹。

4. 输入文件夹名称然后点击底部【确定】按钮，文件夹创建成功，名称前会有文件夹图标与程序进行区别，若想要取消新建文件夹，则点击【取消】按键。

5. 注意事项：文件夹名称必须为以字母/汉字开头的两位及以上的字符串，新建文件夹名称不能为已有文件夹的名称，文件夹名不能超过30位。

![](./assets/ugqrya3txpybolbjdy2lu.png)

![](./assets/j7hd08r4pzpwnoxtaxoec.png)

#### 新建工程

1. 点击【工程】进入工程界面。

2. 点击新建，进入新建界面。

3. 下拉框选择程序，若想将程序创建到文件中可在程序文件件下拉框中选择。

4. 输入程序名称后点击底部的【确定】按键，程序创建成功，并跳转到程序指令界面；若想要取消新建程序，则点击【取消】按键。

注意事项：程序名称必须为以字母/汉字开头的两位及以上的字符串，新建程序名称不能为已有程序的名称，程序名不能超过30位。

程序创建成功后在工程界面就会出现新建的程序名称。

![](./assets/d3zglto9bkxxha4tk1fx6.png)

### 打开

1. 点击【工程】，进入工程预览界面。

2. 选中想要打开的程序或者文件夹。

3. 点击底部的【打开】按键，程序打开成功。

### 操作

点击操作按钮可以对程序执行移动、复制、重命名、批量删除、设为主程序、镜像程序、加密操作。

1. 移动

- 选中程序，点击操作，点击移动到

- 选中工程主界面或任意文件夹

- 点击确定可以选择移动到程序主界面或任意文件夹内，可点击取消不移动

![](./assets/3h-hdy_n0nwlw7z59jyoc.png)

![](./assets/vzjr39r8ly9gn0phyodms.png)

2. 复制:用户复制已有的程序，支持用户在修改程序之前对原有的程序做一个备份操作。

- 进入【工程】界面。

- 选中需要复制的程序.

- 点击底部的【操作】按键，选择【复制】，在复制程序提示界面点击【确定】程序复制成功，点击【取消】则取消程序的复制操作。复制的程序名称用户也可以修改。

- 复制成功后在工程界面会显示复制的程序。

![](./assets/1foemdx1xqigiqo0hgfsr.png)

![](./assets/jydkh37wxrmeglgqby2zs.png)

3. 重命名：对选中的原有程序进行重命名操作

注意事项：重命名的程序的程序名不能为已有程序的名称，前后台的程序的程序名不能重复.

- 点击【工程】，进入工程界面

- 选中需要重命名的程序

- 点击底部的【操作】按键，选择【重命名】，在工程预览界面重新给程序命名

- 点击程序预览界面的【确定】，程序重命名成功。原有的"程序9"重命名为"测试程序9"，点击【取消】则取消程序的重命名操作

![](./assets/ru96xsrnawbmxxuus9nbu.png)

![](./assets/cfkgq_jx3o3la3do-fena.png)

4. 批量删除：一次可以删除多个程序，批量选中仅能选中当前页的程序，无法删除上一页或下一页的程序。

- 点击【工程】，进入工程界面。

- 点击底部的【操作】按键，选择【批量删除】。

【全选】：选中当前页面的所有程序，删除当前页面的部分程序可以直接点击当前页面的程序或者示教器右侧的滚轮键选择程序。

【反选】：如下图，如果现在选中的程序是程序9、程序8、程序7、程序6、程序5、程序4，点击反选会选中程序3、程序2、程序11、程序10。

【取消】：取消对程序的批量删除操作。

【确定】：点击确定按键后在弹出的提示框中点击【确定】按键则选中的程序批量删除成功，点击【取消】退出批量删除。

![](./assets/mconvlgo5owftu4qljeyg.png)

![](./assets/ykksnrcaebwn5rdktbadm.png)

5. 设为主程序。

如果在程序里面插入了较多的调用子程序指令，设为主程序这个操作方便用户在运行程序时知道哪一个程序是主程序。

- 点击【工程】，进入工程界面，选中程序。

- 点击底部的【操作】按键，选择【设为主程序】，设为主程序的程序名前会带一个"\*"号。

![](./assets/k1yzaxuq7qlh4chehmxe0.png)

![](./assets/kdxcjcv5d8js9wlyc-_bs.png)

6. 镜像程序（仅支持六轴串联机器人）

- 选择一个程序

- 点击操作，选择镜像程序

- 选择需要镜像的行号，目标的机器人号，目标作业文件名称，镜像后的坐标系，直角需要选择镜像转换的基准面，用户需要选择转换间距补偿

- 点击确定完成镜像

![](./assets/fvucltldcahbowrqkw6of.png)

![](./assets/7kuirmxdiyiia-hi_klos.png)

镜像程序参数说明：

- 转换程序行号区间：对选择的行号点位进行镜像

- 目标轴组：当有多个机器人时可将程序镜像到其他机器人上

- 目标程序：镜像后创建的作业文件名称

- 转换坐标：镜像后点位坐标

- 转换基准：直角坐标按XZ平面进行镜像

7. 加密、解密

- 选择程序，点击操作，点击加密

- 加密后的程序允许查看，不允许操作（修改，删除复制等），且在最右侧有锁标识

- 选中已加密作业文件点击操作，点击解密完成解密（解密后程序恢复修改可修改操作）

![](./assets/qwpgqvh-_jljyg5swhdjb.png)

![](./assets/u1urexgyph0gpzfogwhlu.png)

## 示教模式操作

用户可以通过使用示教器右上角的【模式选择钥匙】可以在三种模式（"示教模式"、"运行模式"、"远程模式"）间切换。

示教模式下可以完成机器人的系统参数设定、点动操作、作业文件编程等各项操作。

运行模式速度如何计算？

| 参数 | 说明 |
| :--- | :--- |
| 运行模式     | 关节：最大轴速度=额定正速度\*指令速度\*全局速度（状态栏速度）<br>直角：最大线速度=指令速度\*全局速度（状态栏速度）<br>曲线：以第一条曲线速度为轨迹速度 |

### 加速度参数

加速度倍数越大，表示机器人到达最大加速度的时间越快。

1. 点到点指令修改加速度参数

进入【设置-机器人参数-关节参数】调整最大加速度参数

![](./assets/phixagpibjomxvkzqrwhd.png)

- 最大轴速度=额定速度\*全局速度\*指令速度。

例如：点到点指令，全局速度为50%、指令速度为40%、指令加速度为10%、额定速度为200°/s、最大加速度为4倍。

最大轴速度=200°/s\*50%\*40%=40°/s。

运行到额定速度时间=（额定速度\*全局速度\*指令速度）/（额定速度\*最大加速度\*全局速度\*指令加速度）=（200°/s\*50%\*40%）/（200°/s\*4\*50%\*10%）=1s。

2. 直线指令修改最大加速度参数

进入【设置-运动参数-通用运动参数】调整最大加速度参数。

![](./assets/llq1habcsfgfmfktbo0av.png)

- 最大线速度=全局速度\*指令速度。

例如：直线指令，全局速度为30%、指令速度为1000mm/s、指令加速度为50%、最大线速度为2000mm/s、最大线加速度为2倍。

最大线速度=全局速度\*指令速度=30%\*1000mm/s =300mm/s。

运行到额定速度时间=（全局速度\*指令速度）/(笛卡尔最大速度\*笛卡尔最大加速度\*指令加速度\*全局速度)
=（30%\*1000mm/s）/（2000mm/s\*2\*50%\*30%）=0.5s。

4. 根据最大正转速，减速比计算额定正速度。

额定正速度=额定正转速 \* 360 / 60 / 减速比。

## 断点运行

断点运行：运行程序时进行下电或者其他导致程序运行中断的操作，当程序再次启动运行时从运行中断的点继续运行。

运行模式断点运行举例说明：

![](./assets/lgjfzq9xkwf9a2c0qkglh.png)

1. 运行模式程序运行过程中（第一条指令除外）,切换至其他模式时导致运行中断，会将中断时的变量状态、程序运行位置存为断点，断点执行不会清状态。

2. 再次切到运行模式点击【启动】时会弹出提示框，选择"断点执行"则从断点处继续运行，选择"重新运行"则断点消失从第一条指令重新运行。

3. 清断点操作：

- 运行模式进行回零、复位、运行其他程序、运行到该点、重启控制器、修改机器人参数。

- 运行模式切到示教模式进行指令的插入/删除/移动/剪切/复制粘贴操作。

- 运行模式切到示教模式数值变量/位置变量/程序指令参数。

- 控制器报错。

例如：程序在运行中切模式，进行回零操作，然后再次切运行发现清除断点，如下图。

![](./assets/o5wuw8fcbtaznf6n-vd1v.png)

4. 不清除断点操作

- 运行模式下IO紧急停止/伺服警报/输出信息指令。

- 程序运行时下电退出当前作业文件程序，然后重新运行退出的作业文件。

- 程序运行时下电，切到示教模式点动机器人，然后重新运行退出的作业文件等操作。

### 远程程序设置

点击【设置】-【远程程序】，进入远程程序设置界面。

#### 远程参数

![](./assets/-l10_tzwnkqcfde78y_uq.png)

1. 远程模式速度:切换到远程模式时的全局速度，范围\[1,100\]%。

例如：在远程参数界面将远程模式速度修改为30%，切换到远程模式后的全局速度为30%。

2. IO重复触发屏蔽时间:重复预约程序的屏蔽时间。

例如：设置的重复屏蔽时间是500ms，作业文件"程序2"第一次预约启动后，再次预约"程序2"的话，信号会屏蔽500ms，500ms后再次给信号，"程序2"的状态为预约中。

3. 远程IO程序数量\[10,99\]:远程模式下可以运行的程序数量。

例如：远程参数界面设置IO程序数量20，那在远程IO功能界面的"功能"列会显示为远程IO程序1---远程IO程序20，远程状态提示界面的"功能"列会显示为远程IO程序1输出---远程IO程序20输出，远程程序设置界面的"程序序号"列会显示为程序1---程序20。

注意事项：

- 远程模式界面只显示10个队列，如果选择的程序数量超出10个，队列顺序根据远程程序设置界面选择的程序显示前10个。

- 如果设置了10个以上的远程程序，在远程程序界面只显示前10个，但是通过远程IO可以启动未显示的程序。

例如:远程程序设置界面设置12个程序，在远程界面只显示前10个程序，第11、第12个程序通过设置的启动信号是可以正常启动运行只是在远程界面"程序序号"列不显示而已。

![](./assets/vlaeyqpioumxdjxhpj2j6.png)

4. 启动确认时间\[200,1000\]ms：程序启动确认的时间，假设设置时间500ms,必须有500ms的信号持续触发时间。

5. 预约并启动：信号0-1（按下按钮）0.6秒以上时间后1-0（松开按钮），程序直接运行。

- 开：打开预约并启动，如下图所示在远程模式下给1-4信号后伺服上电且作业文件"程序2"开始启动运行。

- 关：关闭预约并启动，在远程模式下给1-1启动信号后伺服上电，然后在给1-4信号作业文件"程序2"开始运行。

![](./assets/hr2c32_o4dzwwyvmld1ov.png)

6. 预约模式：远程模式下预约程序运行。

预约模式打开：触发远程IO程序1信号→机器人运行；此时若触发远程IO程序2信号，则远程IO程序2为预约中，执行完远程IO程序1后执行远程IO程序2。

预约模式关闭：触发远程IO程序1信号→机器人运行；此时若触发远程IO程序2信号则无效；执行完远程IO程序1后给远程IO程序2给启动信号远程IO程序2运行。

7. 远程IO断点执行：打开开关，远程模式运行程序时可断点执行，关闭则不使用，远程模式断点执行必须打开此开关，

8. 远程IO当前行执行：打开开关，远程模式运行程序时可当前行执行，关闭则不使用，远程模式当前行执行必须打开此开关。

注意：断点开关和当前行开关都没打开的话程序运行时如果中断再次运行就会从首行运行

9. 远程IO程序运行中再次预约：打开预约开关，预约的程序运行中可以再次预约；关闭开关，已预约的程序运行中不可以再次预约，只有程序"已预约"和"未预约"状态才可以预约

#### 远程状态提示

![](./assets/bvnij0dcno0nb8pesx6ht.png)

程序在远程模式下运行时，设置的IO输出端口的值会有变化，通过端口数值的变化可以知道当前的程序处于什么状态。

1. 远程IO程序输出：对应远程IO功能界面的远程IO程序1，当远程IO程序1选中的程序开始运行时，选中的IO端口输出提示。

3. DOUT序号：选中IO端口后程序运行时对应端口输出提示。

4. 相关值：

- "0"程序运行时对应的端口是低电平状态。

- "1"程序运行时对应的端口是高电平状态。

- "闪烁"程序运行时对应的端口闪烁变化。

注意事项：程序远程模式运行时，只有程序状态为暂停状态和运行状态时设置IO输出端口才会输出提示，程序状态为停止时IO输出端口不会输出提示。

#### 远程运行状态说明

无预约：进入远程模式后没有预约过程序或预约后又取消预约，显示无预约。

预约中：程序运行过程中触发对应程序的IO口即成功预约程序，取消需再次触发该程序对应的IO口。

运行中：程序正在运行。

已预约：程序运行完成显示已预约。

暂停：程序在运行过程中触发了暂停信号，程序状态为暂停。

程序出错：程序在运行过程中出现报错，此时运行的程序状态为程序出错。

注意事项：程序预约运行的话需要远程参数界面打开预约模式。

假设需要运行的程序队列1、队列2、队列3分别为程序1、程序2、程序3。

1. 触发远程IO程序1信号→触发启动信号→机器人运行，此时程序1的状态为运行中。

2. 触发远程IO程序2信号-程序2运行状态为预约中，程序1运行结束后程序2运行。

3. 触发远程IO程序3信号-程序3运行状态为预约中，程序2运行结束后程序3运行。

### 远程IO断点，当前行执行

远程模式IO断点执行和当前行执行需要打开开关，否则当程序在运行过程中切模式或者其它操作导致程序运行停止再次运行程序时断点和当前行不生效。

## 远程模式Modbus启动程序

### Modbus启动程序

1. 作业文件编程。

2. 点击设置-外部通讯-modbus程序，进入程序选择界面选择需要运行的目标程序。

3. 4X类型地址码6写2，操作模式切换为远程模式（需要拔出示教器）。

4. 4X类型地址码29写1，伺服就绪。

5. 地址码选择作业文件，4x类型地址码45填写数值，填写的数就是对应程序序号选中的程序。

例如：需要运行的是程序序号4的作业文件"程序21"则4x类型地址码45写4。

6. 4x类型地址码19写1，运行作业文件"程序21"，此时当前选中的程序状态为运行。

![](./assets/hjszljpbwdzjd14dnwqol.png)

说明：如果需要设置运行次数、运行速度等其它参数可以参考《modbus地址码列表》进行设置。

### Modbus断点，当前行运行

Modbus远程启动程序运行时程序在运行过程中切模式或者其它操作导致程序运行停止，再次启动程序可断点执行、当前行执行。

4x类型地址码19写0，停止运行；

4x类型地址码19写1，启动运行；

4x类型地址码19写2，暂停运行；

4x类型地址码19写3，断点执行；

4x类型地址码19写4，当前行执行；

4x类型地址码169写4，设置当前机器人当前运行行好号。

### Modbus与io优先级

## AI 检索专用问答对 (Q&A for Retrieval)

**Q: 示教器开机前需要进行哪些安全确认？**

A: 示教器开机前需要检查伺服、控制器、示教盒各部件连接线是否已连接完好，并确认急停按钮正常。

**Q: 如何启动伺服电源？**

A: 将机柜面板上的主电源开关旋转到接通(ON)位置，然后按下机柜面板上的绿色伺服启动按钮。

**Q: 如何通过DEADMAN按键上电？**

A: 轻按示教器的【DEADMAN】按键（示教器背后的按键），机器人上电，示教器上显示"伺服运行"，表示伺服电源成功接通。

**Q: 如何导入机器人配置文件？**

A: 点击【设置】-【机器人参数】-【机器人类型】界面设置机器人类型，然后点击【设置】-【系统配置】-【导入控制器配置】选择配置文件，系统重启后机器人参数配置导入成功。

**Q: 导入配置文件后需要检查哪些内容？**

A: 导入配置文件后需要检查伺服顺序、模型方向和零点位置，确保点动机器人时伺服从站顺序正确、实际方向与模型方向一致、零点位置准确。

**Q: 如何新建工程程序？**

A: 点击【工程】进入工程界面，点击新建，选择程序类型，输入程序名称后点击【确定】即可。程序名称必须为以字母/汉字开头的两位及以上的字符串，不能超过30位。

**Q: 如何对程序进行加密操作？**

A: 选中程序，点击操作，点击加密。加密后的程序允许查看，不允许操作（修改、删除、复制等），且在最右侧有锁标识。

**Q: 什么是镜像程序功能？**

A: 镜像程序功能可以将程序中的点位按指定平面进行镜像转换，仅支持六轴串联机器人，可用于对称工件的编程。

**Q: 如何批量修改指令参数？**

A: 点击【操作】-【批量模式】，选中需要修改的多条指令，选择【修改】，打开需要修改参数的使能开关，输入参数值后点击【确定】。

**Q: 什么是单步运行？**

A: 单步运行是指按下单步按键后，机器人执行选中的指令行，执行完后停止，选中行自动跳转到下一行，可以逐条运行程序。

**Q: 什么是试运行？**

A: 试运行功能是示教模式下将【启动】键作为试运行按键，上电按住【启动】键保持运行，松开停止。试运行支持所有指令，但不支持倒序以及后台程序。

**Q: 示教模式下单步关节速度如何计算？**

A: 单步关节速度=全局速度×指令速度×关节额定正速度，最大速度限制为关节额定正速度×30%。

**Q: 示教模式下单步直角速度如何计算？**

A: 单步直角速度=全局速度×指令速度，最大速度限制为300mm/s。

**Q: 什么是全局速度分段？**

A: 全局速度分段功能允许用户设置多个速度段，每个速度段可以单独命名和设置速度，速度段依次递增，最后一段速度低于100时可新增速度段。

**Q: 如何设置主程序？**

A: 选中程序，点击【操作】-【设为主程序】，设为主程序的程序名前会带一个"*"号，方便在运行程序时识别主程序。

**Q: 如何实现跨作业文件指令操作？**

A: 在批量模式下选中需要复制的多条指令并复制，然后点击【工程】打开目标作业文件，选中粘贴位置后点击【粘贴】即可将指令粘贴到另一个作业文件中。
